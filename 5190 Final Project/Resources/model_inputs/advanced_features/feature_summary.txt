Advanced Feature Summary
========================================

These features describe headline structure/style.
They are intended for classical models such as random forests,
gradient boosting, MLPs, or stacked ensembles.

Feature columns:
- headline_length_words
- headline_length_chars
- avg_word_length
- num_uppercase_words
- num_digits
- num_exclamation_marks
- num_question_marks
- num_commas
- num_colons
- num_semicolons
- contains_quote
- contains_colon
- contains_question
- contains_number
- starts_with_how
- starts_with_why
- starts_with_what

Train feature shape:
(2279, 20)

Validation feature shape:
(760, 20)

Test feature shape:
(760, 20)
